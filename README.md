# MATLAB BER receiver experiment

النسخة الحالية في `code1233_link.m` تقارن LS وLMMSE وCNN مع مرجع القناة والتوقيت المثاليين، باستخدام 512-QAM تجريبية وLDPC وHybrid Beamforming لطبقة واحدة. يدعم الاختبار 32 هوائيًا في كل طرف أو 64 هوائيًا في كل طرف، وثماني سلاسل RF، ومدى SNR من 0 إلى 20 dB.

```matlab
code1233_link(512,96,"results32",32,[0:.5:10 11:20],5000);
code1233_link(512,96,"results64",64,[0:.5:10 11:20],5000);
```

يلزم MATLAB R2025b مع Communications Toolbox و5G Toolbox وDeep Learning Toolbox. يحفظ التدريب نموذجًا واحدًا لكل حجم، ويمكن إعادة استعماله بواسطة `ModelFile`.

يُشغّل workflow المسمى **Practical HBF 512-QAM BER** التدريب والاختبارات الأساسية والخارجية والفتحات الإضافية، مع البذور وتقسيم الدفعات الموثقين في ملفه. النتائج العددية لهذه الدفعات تختلف عن تشغيل 96 فتحة متصلة ببذرة واحدة في المثال أعلاه.

تفاصيل مصفوفات التوجيه وتعريف SNR والتدريب والافتراضات موجودة في [Review-and-assumptions.md](Review-and-assumptions.md). بيانات الاختبار الخارجية DeepMIMO هي بيانات تتبّع أشعة، وتحتاج قياسات IQ فعلية للتحقق الميداني. الملفات `code1233.m` و`cod3.m` والـworkflows الأقدم محفوظات للتجارب السابقة؛ الواجهة الحالية هي `code1233_link`.
